# ملاحظات التحقق المرحلي لوكيل المحتوى

## نتائج موثقة

| الحالة | النتيجة |
|---|---|
| استدعاء `admin-ai` دون JWT | مرفوض بـ `401 unauthorized` قبل أي تحليل أو كتابة. |
| تنفيذ Draft منفذة سابقاً | مرفوض بـ `409 draft_state_invalid` ورسالة توضّح أنها نُفذت سابقاً. |
| تحليل فيديو YouTube من واجهة الإدارة | ظهرت Draft سليمة مرتبطة بـ«الخامس الابتدائي → رياضيات → احمد علي»، مع حفظ Video ID محلياً عند رد YouTube `429`. |
| إلغاء Draft | تعرض بطاقة Preview النوع والمصدر بعد الإلغاء، ولا يتغير أي كورس أو درس. |
| قراءة الصفوف بعد تقوية is_admin | نجحت بـ `200 PLATFORM_READ` وأرجعت «الخامس الابتدائي». |
| الروابط غير الآمنة | `http://` و`https://localhost` لا تُجلب وتعود كتَحذير بلا Draft أو كتابة. |
| قائمة YouTube غير قابلة للاستخراج | تعود بتحذير/Fallback بلا ادعاء بيانات وبلا Draft عند عدم طلب الاستيراد. |
| منتقي ملفات CSV في الواجهة | قبل العينة المحلية وأظهر شارة `content-sample.csv` قبل الإرسال؛ لم يُرسل الملف ولم يتغير المحتوى. |
| منتقي ملفات JSON في الواجهة | قبل العينة المحلية وأظهر شارة `content-sample.json` قبل الإرسال؛ لم يُرسل الملف ولم يتغير المحتوى. |
| منتقي ملفات XLSX في الواجهة | قبل العينة المحلية وأظهر شارة `content-sample.xlsx` قبل الإرسال؛ لم يُرسل الملف ولم يتغير المحتوى. |
| منتقي ملفات TXT في الواجهة | قبل العينة المحلية وأظهر شارة `content-sample.txt` قبل الإرسال؛ لم يُرسل الملف ولم يتغير المحتوى. |
| منتقي ملفات Markdown في الواجهة | قبل العينة المحلية وأظهر شارة `content-sample.md` قبل الإرسال؛ لم يُرسل الملف ولم يتغير المحتوى. |
| نطاق YouTube | رابط `example.com` الذي يحمل `v=` عومل كرابط خارجي فقط: `EXTERNAL_URL`، صفر دروس، بلا Draft. |
| تنفيذ Draft بلا اعتماد | مسودة بحالة `draft` رفضت بـ`409 draft_state_invalid` ورسالة تطلب اعتماداً صريحاً، دون تغيير حالتها أو المحتوى. |

## ملاحظة أمنية

أزيل تحذير `SECURITY DEFINER` الخاص بالدالة `public.is_admin()` بتحويلها إلى `SECURITY INVOKER`. بقي تحذير إعداد Supabase المبدئي بشأن **Leaked Password Protection** مع رابط المعالجة الرسمي في تقرير التسليم.
